## 外观约束

保留成年女性、温暖棕眼、自然微笑、圆润但非幼儿化的面部比例。发型为深棕侧分短 bob，长度在下颌到上颈，避免长发和二次元平面色块。服装仅露米白衬衫领与上肩。材质柔和、有皮肤与头发层次，不能通过高光塑料质感代替精细建模。

前脸与头发是验收重点。不要制作全身、办公室、手部、衣物物理或复杂动作，以控制首版工作量。脸部需在应用实际显示尺寸下仍有亲和力，不能只提供离线渲染宣传图。

## 交付给当前项目的技术格式

首选：VRM 1.0、完整内嵌纹理、标准 humanoid（保留标准骨架；下身可以保持基础隐藏网格，画面只用头肩）。必须能由当前 three-vrm 3.5.5 读取。

如果模型师只交付头肩 GLB，需要先确认更改本地加载器和表情映射；现有 AvatarModel 使用 VRM humanoid/head 与 expressionManager，不能保证 GLB 直接替换。不能把缺失表情的静态头当成已完成。

至少包含：

| 项目 | 要求 |
| --- | --- |
| 嘴型 | VRM aa、ih、ou、ee、oh，连续 0–1 权重，无明显穿模 |
| 眼部 | blink、blinkLeft、blinkRight；闭眼自然，睫毛不穿眼球 |
| 情绪 | neutral、happy、relaxed；可选 sad/surprised，小幅度即可 |
| 骨骼 | 头/颈可小幅旋转，不拉扯脸颊与发际线 |
| 纹理 | 优先 1K–2K、嵌入文件；不依赖远程 URL 或 Blender 过程材质 |
| 着色 | 当前本地 WebGL 中真实预览通过；不以 Cycles 离线效果代替 |
| 规模 | 头肩网格与贴图由实际性能确定，初始目标总面数≤约5万三角、文件≤约15MB，属于制作预算而非已实测指标 |
| 来源 | 提供原始 .blend/工程与贴图、VRM、许可说明、作者署名、第三方素材清单 |

所有依赖素材需要允许本产品商用、修改和随安装包分发；免费直播使用许可不等于安装包分发许可。保存原始许可链接、文件哈希与修改说明。对署名要求，在产品许可目录和必要 UI 中落实。

## 接入与验收步骤

1. 原始模型在独立预览中对照 01，检查脸型/发型/眼神；达标后才更换产品资源。
2. 验证 VRM 解析、贴图完整、expression presets、头骨位置与包围盒。对缺失项明确报错。
3. 保留当前 TTS 音量驱动 aa，不改变语音、字幕、服务器协议或钱包；后续增加音素级嘴型须另行确认。
4. 调整固定头肩相机，去掉原办公室背景，使用安静中性底色，头顶和两侧不得裁切。
5. 说话、静音闭嘴、倾听点头、眨眼、暂停、结束与减少动态各录制/截图检查；断网模型加载与 WebGL 丢失需可恢复。
6. 本机 Electron 与 Windows 实机检查，并做 30 分钟资源记录；保留手动切回 2D，不能静默降级。
