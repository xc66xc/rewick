# 掌灯 Rewick

0.4.0 桌面客户端，面向 Apple Silicon Mac 的实时面试辅助工作台。阿里云流式转写、自定义回答模型与平台服务按能力独立使用。

桌面客户端位于 `frontend/`，以下开发命令均在本目录执行；独立 Java 服务位于 `../backend/`，整体启动方式见[仓库说明](../README.md)。打包产物写入仓库根目录的 `dist/`，应用身份和已有用户数据位置保持原机制。此前 0.4.0 macOS arm64 安装曾完成原路径更新及文件/数据校验；本次源码改动未更新安装包，也未云部署。历史状态见 [0.4.0 实现记录](../workspace/interview-copilot/notes/impl-backend-separation.md)。

首次进入显示邮箱登录页，登录后才开放工作台，包括用户自定义服务。可切换到「注册账号」，发送邮箱验证码、设置密码并「注册并登录」；已注册邮箱再次发送注册验证码时，会提示直接登录或找回密码，不重复发送注册邮件。登录页的「找回密码」填写邮箱、新密码和确认密码后发送验证码，验证成功才修改密码并返回登录页，不自动登录；新密码至少 12 个字符且最多 72 个 UTF-8 字节，密码与验证码均不落盘。已有账号使用邮箱与密码登录。登录页不提供地址输入；开发/构建时通过环境变量 `COPILOT_PLATFORM_URL` 指定后端，未设置时使用 `https://api.junshi.icu`。平台域名必须使用 HTTPS；显式 IPv4/IPv6 地址与 localhost 允许 HTTP，HTTP 不提供传输加密。注册需要管理员先配置邮件服务。平台凭证使用系统安全存储加密，密码不落盘，页面不会取得业务 Token。更换平台地址会清除登录；退出或登录失效会取消转写、回答、检索及连接测试并返回登录页，晚到回包不会恢复旧登录。

「模型与设置」提供回答模型、实时语音转写、远程知识库三类下拉框，按「平台提供」和「我的自定义」分组。明确选择哪一项就使用哪一项，不按是否存在 Key 自动切换。平台只返回可用模型与已绑定的服务名称；资料向量模型只由管理员配置，用户无需填写 Key。平台服务下架、自定义服务删除或连接失败均不会悄悄改用其他服务。

下拉框的「+ 自定义模型/服务…」打开独立草稿，填写名称、地址、模型或 Agent ID 和 Key；「测试连接」只测试草稿，「保存并选用」才持久化并选中。自定义服务可编辑、删除，Key 加密留在本机；同一配置密码框留空保留原 Key，更换地址需重新填写。平台地址、Key、模型/Agent 绑定全部由管理后台存入数据库，桌面无需填写供应商连接信息；平台供应商 Key 不包含在桌面应用中。

## 联网搜索

管理员把用户加入「高级设置授权用户」后，桌面设置显示「开启联网搜索」。账号开关默认关闭，保存后随账号同步；后端未启用 Tavily 时开关不可用。授权撤销后清除开关，重新授权需再次开启。Tavily 地址、Key、topK、搜索深度与超时统一在管理后台「模型与服务」的联网搜索服务中配置，凭据加密保存于数据库；保存后新请求立即使用新配置，桌面不保存 Tavily 凭据，也不从 YML 读取。

开启后，每次回答使用当前问题并行检索 RAG 和网上资料，再共同交给选中的回答模型；关闭 RAG 时仍可独立联网检索，平台模型和自定义模型均支持。网页资料只作为技术参考，不能当作个人经历。回答下方显示联网状态与网页来源，点击来源可在浏览器打开。联网失败或超时会提示并继续回答，登录失效、结束面试或取消生成则停止请求。

资料按 RAG、网页片段顺序保存到实际模型输入和会话历史；开发模式回答 Excel 导出沿用同一顺序，`reference` 留空。联网状态和来源在正式版也可查看，完整模型输入调试入口仍仅开发模式显示。

## 使用

1. 使用下方开发命令启动，或打开新构建的 `../dist/mac-arm64/掌灯 Rewick.app`；现有安装包不会因源码修改自动更新。
2. 在登录页注册或登录邮箱账号，然后在右上角设置选择平台转写或添加自己的转写服务。自定义转写预填北京地域 `fun-asr-realtime`，Key、模型与地域需要匹配；选择平台转写时由后端提供绑定模型与凭据。
3. 在回答模型下拉框选择平台模型，或添加兼容 Chat Completions 的自定义服务。自定义回答预填 DeepSeek 接口；本机 Ollama 可使用 `http://localhost:11434/v1` 和已安装的模型名称。回答风格可选「简短口语」（通常 3–5 句）或「展开口语」（通常 2–3 段）。
4. 在「个人背景」分别保存多份简历、目标岗位 JD 和参考资料；简历与 JD 可导入文字层 PDF、`.md`、`.txt`，核对预览后保存，也支持直接粘贴。
5. 在「面试环境」创建命名环境，选择一份简历、一个目标岗位以及要使用的参考资料，保存后点击「进入面试」。然后在工作台选择「系统音频」或「麦克风」，点击开始转写。首次使用按 macOS 提示允许相应音频权限。系统音频默认开启「自动回答」：问题字幕定稿后等待约 1.5 秒没有新字幕，自动生成口语答案，转写继续进行。可选择 1/1.5/2.5 秒等待；麦克风保持手动回答。
6. 点击某条转写旁的 **回答这句**，直接针对该句生成答案，并参考截至该句的对话和个人背景；不会覆盖「当前问题」里的草稿。临时字幕也可以点击，以点击当时的文字为准。
7. 也可以按 **⌘⇧Enter**，或在「当前问题」输入文字后点「生成回答」。这两种方式填了问题时优先回答该问题，留空时使用最近字幕。提交后立即清空输入框，原问题保留在答案卡中；生成期间可以继续输入下一题，后续响应不会清掉新草稿。模型未配置等前置校验失败时保留输入。
8. 可停止生成、置顶窗口、切换紧凑模式。在「会话记录」查看或导出 Markdown。

开发模式的会话详情页额外提供「导出回答 Excel」，生成兼容 `ragas_excel` 输入模板的 `.xlsx`：工作表 `data`，列为 `id`、`user_input`、`response`、`retrieved_contexts`、`reference`。编号从 1 递增，问题与检索正文优先取实际模型输入快照，旧记录取保存的问题和检索片段；片段按原顺序写成 JSON 数组，无检索时为 `[]`。没有正文的回答跳过，已生成的部分正文保留，超长单元格报错而不截断。`reference` 按要求留空，运行评估前需手动补填标准答案。生产构建移除按钮、桥接方法与导出处理器；ExcelJS 仅作为开发依赖。

转写文字可以直接点击定位光标、选中替换或输入，不需要进入编辑模式。支持中文、多行与系统撤销；离开文本框时自动保存。修正后的文字用于「回答这句」、后续问题上下文、历史和导出。仅点击未修改时，离开后继续显示最新识别结果；手动修改过的整句会标为「已修改」并保留你的版本，后续语音继续转写为新句。

长问题被转写切成多段时，依次点击每段旁的 **加入问题**。文字按点击顺序换行追加到「当前问题」，保留原有手输草稿；加入采用点击时显示的文字，后续识别修订不会改写已加入的内容。按钮短暂显示「已加入」，防止快速连续点选同一段。合并时输入框最多自动展开三行，仍可自行修改；拼好后点击生成或使用快捷键，完整问题才会发送到知识库和回答模型，随后清空输入框。

首次成功加入后，系统音频的自动提交会临时暂停，转写和已有回答继续运行；直到「当前问题」成功通过校验并提交，或点击「清空」/手动清空输入框后，才按当前自动回答开关恢复。合并期间收到的旧段及其后续修订不会补发，之后的新段正常处理。单独点击「回答这句」、切换页面、窗口失焦或停止转写均保留合并草稿；新会话/切换面试环境沿用原清空规则。加入后超过 12,000 字符会提示删减，不截断或覆盖草稿。

自动回答会合并相邻的连续句，同一句不因识别修订而重复触发；上个回答还没完成时，下一批问题先排队。点击正在等待停顿、定稿或排队的转写句，会取消这一整轮尚未提交的问题（包括一起聚合的句子），改为手动处理；离开编辑器、切回会议或同句识别修订都不会重新触发，可随时点「回答这句」。后续新问题仍正常自动处理。点击已经处理过的旧句不会取消无关的新问题，编辑期间只暂缓新问题。手动生成、取消、关闭自动回答或停止转写会清除待触发内容。开关/等待时长保存后只处理新到的句子，自动提问不会使用「当前问题」里的草稿。

回答区域优先保留阅读空间，问题输入框默认一行，可按需拉高。模型输出新文字或新增回答时，列表不会自动滚动；点击回答区右上角「查看最新回答」才会跳到最新题的开头，后续输出继续保持当前阅读位置。

普通工作台顶部采用单行标题和环境摘要，收紧留白，将更多高度留给转写与回答。较长的公司、岗位、环境名和简历名称省略显示，悬停可查看完整文字；「编辑个人背景」和「选择面试环境」入口仍在顶部。

「先简单介绍一下自己」等口语邀请也会触发。状态区会说明当前是在等待语音定稿、等待停顿，还是没有识别为提问；后一种情况可用「回答这句」补答。保持转写开启，停顿结束后自动生成，无需先停止转写。

自动回答在字幕定稿并停顿后提交，不要求内容符合问句格式。整段仅由「嗯」「好的」「对」「是的」「明白了」「OK」等附和词组成时跳过自动生成，原文仍保留在转写和上下文中；同批字幕里的纯附和不拼入当前问题。「为什么」「然后呢」「继续」「展开讲讲」及「嗯，你具体怎么实现的？」正常触发，带问号的简短疑问也保留。临时字幕尚未定稿时不提前过滤，避免「嗯」后续补成问题被遗漏；手动输入和「回答这句」不受影响。此规则不能覆盖所有附和表达，也不能区分系统音频中的说话人；误判时可关闭自动模式或手动补答。网络错误仍需重新开始转写。

无需转写 Key 也可以手动输入问题测试回答模型。应用没有内置可用的供应商 API Key；可使用自己的 Key、无 Key 的本机回答模型，或已登录且后端已启用的相应平台能力。

## 简历、岗位与参考资料

「我的简历」支持最多 50 份命名简历，每份最多 100,000 字符。「新增简历」创建独立草稿，「选择简历」切换要编辑的文件；导入只改变草稿，保存后更新该条资料，不自动更改环境的选择。切换有未保存改动的草稿时可保留或放弃。取消、空白、损坏或加密 PDF 不会覆盖原内容。支持文字层 PDF，扫描件需要先做 OCR；多栏和表格需在预览中核对顺序。

「目标岗位」支持最多 50 个命名方案，每个包含公司名称、岗位名称和最多 12,000 字符的 JD，也可导入 PDF/TXT/MD。被当前环境选中的简历/JD 修订在下一次开始面试时生效，已生成内容保留当时快照。JD 不依赖资料检索开关或向量服务。环境引用中的简历、岗位不能直接删除，需先修改相关环境选择。

「面试环境」最多保存 100 套组合。点击「进入面试」，或保存当前环境的组合修改时，先保存当前会话再清空对话；保存失败不会丢弃当前内容。转写或生成中须先停止才能切换。允许简历/岗位留空或不选资料，空选择不回退到其他环境。新账号由服务器创建空的「默认环境」，旧本地背景不读取、不迁移，需重新录入。每个回答与会话保留环境名称，历史不会被后续编辑改写。

「参考资料」上传 PDF/TXT/MD，每份最多10MB，PDF最多500页。默认每用户20份、总原文件100MB、10000片段，管理员可调整总配额。原文件存服务器持久卷，正文与1024维向量存 PostgreSQL。相同内容不重复上传，旧本地资料需重新上传。

资料索引与问题向量化统一使用管理员配置的1024维平台向量服务。桌面不提供向量地址、模型或Key配置。索引任务在服务器执行，关闭桌面不会中断；失败可点击重建。

百炼关闭时，开启「使用参考资料」并在当前环境勾选已就绪资料。后端仅检索当前用户、当前选择中启用且模型匹配的资料。向量服务失败可使用同范围关键词检索，普通检索故障仍继续回答；认证失效需重新登录。更换平台向量模型后需重建，开启百炼时不额外检索PG。

默认用途「技术参考」只作为知识来源；你自己的项目材料可标为「我的项目经历」。JD 的招聘要求和他人的技术文章不会被指示为你的亲历。答案保持口语正文，下面折叠显示「本次检索资料」及本机记录的文件名/页码；复制只包含正文。历史和 Markdown 导出保留当时的目标岗位及摘录，即使原资料已移除。

环境、简历选择与目标岗位 JD 集中在回答区顶部的「面试信息」中查看，不在每道问题下重复显示；历史查看保留当时快照，同一会话使用过不同配置时注明关联问题。每条回答仍有独立的「本次发送内容」，展开可查看发起请求时的模型名称、完整系统提示词及用户输入（背景、JD、问题、字幕、检索片段）；「复制发送内容」复制原始消息和模型名称，「复制回答」仍只复制回答正文。内容随会话历史保存在本机，之后修改背景、JD 或移除资料不会改写它；请求失败或中途停止也保留已发起请求的文字。旧版回答和提交前停止的请求没有可还原的发送记录。此栏只记录模型输入文字，不包含接口认证头或配置中的 API Key。

会话仍最多保留 50 场，单场 4 MB；完整输入快照会增加会话大小。达到上限时会明确提示新建会话，不会截断输入文字或覆盖之前保存的记录。Markdown 导出保持回答、目标及检索资料的格式，完整模型输入在应用的会话记录中查看或单独复制。

「会话记录」列表及详情页都支持删除，确认后移除该场转写、回答和模型输入快照。删除当前空闲会话会同时清空工作台并开始新的会话；当前会话正在转写或生成回答时，需要先停止。删除记录不影响简历、目标岗位、面试环境、参考资料、模型设置或已导出的文件；失败时保留记录，可重试。

## 百炼远程知识库

在「模型与设置 → 远程知识库」下拉框选择平台服务或添加自定义服务，再开启「启用远程知识库」。自定义配置填写完整请求地址、已发布的知识检索服务 Agent ID 和独立 API Key；可先测试草稿再保存选用。选择平台服务无需填写这些供应商信息。自定义请求地址示例为 `https://{workspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/indices/knowledge/search`，须将 `{workspaceId}` 替换为自己的业务空间 ID；Agent ID 为 `aid-…`。此处接入知识检索接口，知识库和检索策略在百炼控制台管理。

远程开关默认关闭，对所有面试环境生效。开启后只检索百炼，暂停个人资料PG检索，向量服务由平台统一管理；资料开关和各环境的资料选择保持原样。关闭远程后，才按原资料开关和环境选择恢复PG检索。本地环境勾选不限制云端检索范围，云端范围由自带配置的 Agent 或平台后端的 Agent 决定。简历和岗位 JD 仍直接作为回答上下文，不受此检索切换影响。

远程自定义 Key 单独加密保存，不复用其他服务 Key；同一配置留空保存会保留旧 Key，选择平台服务无需先删除自定义配置。每次回答前仅将当前问题发送到检索接口，请求体为 `agent_id`、`query` 和空 `images`；平台请求增加所选 `serviceId` 并使用 `agent_id=platform`，真实 Agent 由后端决定，选中 ID 失效会要求重新选择。测试连接使用固定测试问题，不使用简历或会话内容。客户端检索最多等待 5 秒；普通超时、失败或没有结果时会显示状态，继续根据简历、岗位 JD 和问题上下文生成，不会自动检索或回退到本地资料。停止或更换问题会取消旧请求。平台回答仍独立检查登录与额度，知识降级不能绕过回答授权。

远程接口响应只提取 `data.nodes[].text` 正文，不保留接口的 metadata、文件名、页码、评分或媒体链接，也不会访问这些链接。最多保留 6 个文本片段，每片段最多 2000 字符，总计 6000 字符；发送给回答模型的远程参考内容是纯文本片段列表，不含来源标签、内部 ID 或其他资料属性。回答的「本次检索资料」仍标明百炼来源和当时的 Agent 标识，平台模式记录 `platform`，不会返回服务端真实 Agent；「本次发送内容」展示实际发出的文字。历史和导出保留当时的资料，不随云端内容或设置的后续变更而改变；旧版含来源属性或同时包含本地与远程来源的历史仍可查看，不改写过去实际发送的内容。

## 数据与连接

- 用户自带 Key 与平台业务 Token 在 Electron 主进程中通过系统 `safeStorage` 加密保存，读取设置不会向页面返回凭据；平台供应商 Key 仅服务端配置。
- 原始音频不落盘，开始转写后实时发送到自带配置的阿里云兼容 WebSocket 服务，或经平台 Java 后端中转到其配置的语音服务。
- 生成回答时将问题、最近字幕、已保存个人背景、目标公司/岗位/JD 及实际检索到的片段发送到所选回答模型；平台模式经后端调用。口语提示词和输入快照当前仍由客户端构建。
- 参考资料上传后由 Java 后端解析、使用平台 Key 生成1024维向量并存入 PostgreSQL/pgvector。原文件在服务器持久卷。桌面按当前用户与环境检索，启用百炼时暂停个人资料检索；旧本地资料需要重新上传。
- 远程知识库仅发送当前问题到自带配置或平台检索接口；云端返回的相关文字会进入回答模型与会话历史。自带 URL、Agent ID 和 Key 独立配置，平台使用服务端固定配置；同一次请求使用同一版本的连接配置与凭据。
- Java 后端保存账号、凭证摘要、简历、岗位、环境、资料库和正式会话历史，均按登录用户隔离。
- 本地配置与加密的待同步会话草稿保存于 `~/Library/Application Support/Interview Copilot/`，导出文件由用户选择位置。
- 多份简历、岗位与环境保存到服务器 PostgreSQL。桌面只做 PDF/TXT/MD 文字提取与编辑，确认保存时上传正文，不上传原始简历文件，不对简历做向量化。列表按摘要加载，其他正文在选中时读取，保存失败保留草稿；修改使用版本检查，跨设备冲突需刷新后处理。开始面试按点击的环境固定服务器背景快照，之后修改不会改变本场面试。
- 接口地址支持 HTTP/HTTPS，语音连接支持 WS/WSS；仍拒绝地址内的账号、密码与片段。
- 修改转写配置后需停止并重新开始；回答配置在下次生成时生效。

### 打包版调试限制

`electron-builder.yml` 在签名前关闭 `enableNodeCliInspectArguments` 和 `enableNodeOptionsEnvironmentVariable`，禁止 Inspector 与 `NODE_OPTIONS` 注入；同时禁用 `NODE_EXTRA_CA_CERTS`，不支持通过该变量添加自定义 CA。主进程在初始化账户存储及 IPC 前拒绝远程调试端口、管道和 Inspector 启动参数，退出码为 1；打包版窗口设置 `devTools: false`。`npm run dev` 保留调试功能。

```bash
node node_modules/@electron/fuses/dist/bin.js read --app '../dist/debug-hardened/mac-arm64/Interview Copilot.app'
node scripts/check-packaged-debugging.mjs '../dist/debug-hardened/mac-arm64/Interview Copilot.app/Contents/MacOS/Interview Copilot'
```

### TLS 连接重置修复（2026-09-14）

同一 Electron 运行时中，HTTPS Agent 启用 TLS 会话缓存时首次连接成功，后续连接出现 `ECONNRESET`；禁用缓存后连续连接成功。主进程通过 Undici 配置 `connect.maxCachedSessions: 0`，WSS 使用同样禁用会话缓存的 HTTPS Agent。新连接执行完整 TLS 握手，已有 HTTP keep-alive 连接仍可复用；保留 HTTPS/WSS、证书校验、请求超时及禁止重定向，不添加 HTTP 回退或自动重试。代价是重新建立 TLS 连接时增加握手开销。

服务器关闭会话缓存的对照实验未解决问题，已恢复原 Nginx 配置。客户端修复后 HTTPS 平台接口和 WSS 握手连续三轮均到达服务端并返回预期的未认证 401；这证明传输连通，不等于实际音频转写验收。需要重启开发主进程或重新打包，旧进程不会应用新连接器配置。

- 通过托盘/菜单栏选择「退出掌灯 Rewick」（macOS 也可按 ⌘Q）真正退出；先停止工作并等待面试结算（网络请求最多 8 秒）。网络异常时由服务端心跳超时结算。
- macOS 打包通过 `LSUIElement` 避免 Dock 启动闪现；开发运行在 Electron 就绪时隐藏 Dock。

验收：先 `npm run build`，再 `node frontend/scripts/smoke-menu-bar.mjs`（隔离账户与模拟服务）。

### 透明紧凑窗口

紧凑布局采用聊天气泡：问题靠右显示为淡蓝气泡，口语回答靠左、使用深色 19px 正文，多轮问答按顺序保留。顶部显示转写状态、剩余时长和结束操作；环境与模型名称不占据阅读区。顶栏滑杆图标打开透明、共享保护及自动回答设置，底部固定问题输入，点击「发送问题」后清空输入，生成中可停止。回答输出不自动滚动，点击「最新回答」才跳转阅读位置。气泡背景跟随透明度滑块，正文不变淡。

开始面试后，点击右上角「紧凑模式」进入透明窗口；「透明与共享设置」可通过滑块以 1% 步长调整 0%–80% 的背景不透明度，拖动即时预览、松开保存，支持键盘方向键微调（默认 20%，淡色半透明；已保存的设置保持原值），文字不会一起变淡。拖动顶栏移动窗口，拖动边缘调整大小。设置保存在本机用户数据目录的 `window-preferences.json`。

共享保护默认开启，常规与紧凑窗口共用一份本机设置。常规模式从「模型与设置 → 窗口与隐私」调整，紧凑模式从「透明与共享设置」调整；任一入口修改后立即自动保存并同步应用到两个窗口，退出紧凑模式、结束面试和重启均保留该选择。它依赖操作系统捕获排除能力，不能保证所有会议软件都隐藏窗口，尤其是 macOS 的 ScreenCaptureKit 捕获方式。共享前请在实际会议软件中验证效果。退出紧凑模式、结束面试或时长耗尽会恢复完整窗口。

完整窗口和紧凑窗口共用一个 `WebContentsView`，切换不重新创建页面。原生窗口与真实应用流程的隔离验收命令（先执行 `npm run build`）：

```bash
node scripts/smoke-compact.mjs
node scripts/smoke-compact-ui.mjs
```

共享保护同步验收（先构建）：`node frontend/scripts/smoke-content-protection.mjs`。测试检查原生窗口保护标志、两个入口与重启持久化；会议软件实际捕获效果仍需在对应系统验证。
