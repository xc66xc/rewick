# Interview Copilot

0.4.0 桌面客户端，面向 Apple Silicon Mac 的实时面试辅助工作台。阿里云流式转写、自定义回答模型与平台服务按能力独立使用。

桌面客户端位于 `frontend/`，以下开发命令均在本目录执行；独立 Java 服务位于 `../backend/`，整体启动方式见[仓库说明](../README.md)。打包产物写入仓库根目录的 `dist/`，应用身份和已有用户数据位置保持原机制。0.4.0 macOS arm64 已更新到原路径，安装文件和用户数据校验通过；尚未云部署。完整状态见 [0.4.0 实现记录](../workspace/interview-copilot/notes/impl-backend-separation.md)。

平台接入：在「模型与设置」启用平台服务，填写已运行的后端地址（默认 `http://127.0.0.1:8080`）并用后端提供的账号登录。平台凭证使用系统安全存储加密，密码不落盘，页面不会取得业务 Token。更换平台地址会清除登录；退出或切换平台连接会取消相关平台转写、回答、检索及连接测试，晚到回包不会恢复旧登录。后端账号目前由服务端初始化，没有公开注册入口。

每项能力独立选路：已配置自己的回答、转写或远程知识库 Key 时继续直连；没有 Key 时使用已登录平台的对应能力。无需 Key 的本地回答模型仍在本机调用。设置中可显式清除某项自带 Key；留空保存仍保留旧 Key。平台启用后，远程知识库可以不填检索地址、Agent ID 和 Key；仍只检索远程知识库，失败时继续回答。自带 Key 失败不会切换到平台。平台模型名称由后端返回，实际发送内容会记录所用模型。平台供应商 Key 只由后端保存和使用，不包含在桌面应用中。

## 使用

1. 使用下方开发命令启动，或打开已在本机构建的 `../dist/mac-arm64/Interview Copilot.app`；现有安装包不会因源码修改自动更新。
2. 按需启用并登录平台，或在右上角设置填写自己的阿里云百炼转写 Key。自带转写配置默认接北京地域 `fun-asr-realtime`，Key、模型与地域需要匹配；使用平台转写时由后端选择模型与凭据。
3. 设置回答模型，或在无自带回答 Key 时使用平台回答。自带模式默认预填 DeepSeek 接口，也可填写其他兼容 Chat Completions 的服务；本机 Ollama 可使用 `http://localhost:11434/v1` 和已经安装的模型名称。回答风格可选「简短口语」（通常 3–5 句）或「展开口语」（通常 2–3 段）。
4. 在「个人背景」分别保存多份简历、目标岗位 JD 和参考资料；简历与 JD 可导入文字层 PDF、`.md`、`.txt`，核对预览后保存，也支持直接粘贴。
5. 在「面试环境」创建命名环境，选择一份简历、一个目标岗位以及要使用的参考资料，保存后点击「进入面试」。然后在工作台选择「系统音频」或「麦克风」，点击开始转写。首次使用按 macOS 提示允许相应音频权限。系统音频默认开启「自动回答」：问题字幕定稿后等待约 1.5 秒没有新字幕，自动生成口语答案，转写继续进行。可选择 1/1.5/2.5 秒等待；麦克风保持手动回答。
6. 点击某条转写旁的 **回答这句**，直接针对该句生成答案，并参考截至该句的对话和个人背景；不会覆盖「当前问题」里的草稿。临时字幕也可以点击，以点击当时的文字为准。
7. 也可以按 **⌘⇧Enter**，或在「当前问题」输入文字后点「生成回答」。这两种方式填了问题时优先回答该问题，留空时使用最近字幕。提交后立即清空输入框，原问题保留在答案卡中；生成期间可以继续输入下一题，后续响应不会清掉新草稿。模型未配置等前置校验失败时保留输入。
8. 可停止生成、置顶窗口、切换紧凑模式。在「会话记录」查看或导出 Markdown。

转写文字可以直接点击定位光标、选中替换或输入，不需要进入编辑模式。支持中文、多行与系统撤销；离开文本框时自动保存。修正后的文字用于「回答这句」、后续问题上下文、历史和导出。仅点击未修改时，离开后继续显示最新识别结果；手动修改过的整句会标为「已修改」并保留你的版本，后续语音继续转写为新句。

长问题被转写切成多段时，依次点击每段旁的 **加入问题**。文字按点击顺序换行追加到「当前问题」，保留原有手输草稿；加入采用点击时显示的文字，后续识别修订不会改写已加入的内容。按钮短暂显示「已加入」，防止快速连续点选同一段。合并时输入框最多自动展开三行，仍可自行修改；拼好后点击生成或使用快捷键，完整问题才会发送到知识库和回答模型，随后清空输入框。

首次成功加入后，系统音频的自动提交会临时暂停，转写和已有回答继续运行；直到「当前问题」成功通过校验并提交，或点击「清空」/手动清空输入框后，才按当前自动回答开关恢复。合并期间收到的旧段及其后续修订不会补发，之后的新段正常处理。单独点击「回答这句」、切换页面、窗口失焦或停止转写均保留合并草稿；新会话/切换面试环境沿用原清空规则。加入后超过 12,000 字符会提示删减，不截断或覆盖草稿。

自动回答会合并相邻的连续句，同一句不因识别修订而重复触发；上个回答还没完成时，下一批问题先排队。点击正在等待停顿、定稿或排队的转写句，会取消这一整轮尚未提交的问题（包括一起聚合的句子），改为手动处理；离开编辑器、切回会议或同句识别修订都不会重新触发，可随时点「回答这句」。后续新问题仍正常自动处理。点击已经处理过的旧句不会取消无关的新问题，编辑期间只暂缓新问题。手动生成、取消、关闭自动回答或停止转写会清除待触发内容。开关/等待时长保存后只处理新到的句子，自动提问不会使用「当前问题」里的草稿。

回答区域优先保留阅读空间，问题输入框默认一行，可按需拉高。模型输出新文字或新增回答时，列表不会自动滚动；点击回答区右上角「查看最新回答」才会跳到最新题的开头，后续输出继续保持当前阅读位置。

普通工作台顶部采用单行标题和环境摘要，收紧留白，将更多高度留给转写与回答。较长的公司、岗位、环境名和简历名称省略显示，悬停可查看完整文字；「编辑个人背景」和「选择面试环境」入口仍在顶部。

「先简单介绍一下自己」等口语邀请也会触发。状态区会说明当前是在等待语音定稿、等待停顿，还是没有识别为提问；后一种情况可用「回答这句」补答。保持转写开启，停顿结束后自动生成，无需先停止转写。

问题检测使用本地问句规则和字幕停顿，不能保证准确识别所有口语或区分系统音频中的说话人；误判时可关闭自动模式或手动补答。网络错误仍需重新开始转写。

无需转写 Key 也可以手动输入问题测试回答模型。应用没有内置可用的供应商 API Key；可使用自己的 Key、无 Key 的本机回答模型，或已登录且后端已启用的相应平台能力。

## 简历、岗位与参考资料

「我的简历」支持最多 50 份命名简历，每份最多 100,000 字符。「新增简历」创建独立草稿，「选择简历」切换要编辑的文件；导入只改变草稿，保存后更新该条资料，不自动更改环境的选择。切换有未保存改动的草稿时可保留或放弃。取消、空白、损坏或加密 PDF 不会覆盖原内容。支持文字层 PDF，扫描件需要先做 OCR；多栏和表格需在预览中核对顺序。

「目标岗位」支持最多 50 个命名方案，每个包含公司名称、岗位名称和最多 12,000 字符的 JD，也可导入 PDF/TXT/MD。被当前环境选中的简历/JD 修订在下一次回答生效，已生成内容保留当时快照。JD 不依赖资料检索开关或向量服务。环境引用中的简历、岗位不能直接删除，需先修改相关环境选择。

「面试环境」最多保存 100 套组合。点击「进入面试」，或保存当前环境的组合修改时，先保存当前会话再清空对话；保存失败不会丢弃当前内容。转写或生成中须先停止才能切换。允许简历/岗位留空或不选资料，空选择不回退到其他环境。首次升级会将原有单份背景、岗位和当时已启用资料迁入「默认环境」，原设置、Key 和历史保留。每个回答与会话保留环境名称，历史不会被后续编辑改写。

「参考资料」可多选 PDF/TXT/MD，最多 30 份，每份不超过 10 MB、100 页，总计最多 5,000 个片段。文件保存在应用私有目录，移动原文件不影响资料；移除只删除应用副本。相同内容不重复导入，同名不同内容可独立管理。

使用本地资料 RAG 前，在设置中填写独立的向量服务地址、模型、维度与 Key，保存并测试向量接口。默认阿里云 `text-embedding-v4`、1024 维；地址与 Key 的地域/业务空间需匹配，也可使用兼容 Embeddings 的自定义服务。向量 Key 与语音/回答 Key 分开保存，不自动复用。未配置时可先导入、预览，等待建索引。

百炼远程知识库关闭时，开启「使用参考资料」，并在面试环境中勾选已处理完成的资料，即可使用本地检索。只有环境已勾选、全局已启用且索引可用的本地文件参与检索；新增资料不会自动进入环境。所有生成入口的本地检索都限于该范围，本地语义请求超时或失败会显示使用本地关键词匹配。未选资料不检索本地全库；没有相关资料时不硬塞摘录。更换向量模型或维度需要重建，旧向量不会混入新的向量空间。开启百炼后本地检索暂停，本地开关和环境选择继续保留。

默认用途「技术参考」只作为知识来源；你自己的项目材料可标为「我的项目经历」。JD 的招聘要求和他人的技术文章不会被指示为你的亲历。答案保持口语正文，下面折叠显示「本次检索资料」及本机记录的文件名/页码；复制只包含正文。历史和 Markdown 导出保留当时的目标岗位及摘录，即使原资料已移除。

环境、简历选择与目标岗位 JD 集中在回答区顶部的「面试信息」中查看，不在每道问题下重复显示；历史查看保留当时快照，同一会话使用过不同配置时注明关联问题。每条回答仍有独立的「本次发送内容」，展开可查看发起请求时的模型名称、完整系统提示词及用户输入（背景、JD、问题、字幕、检索片段）；「复制发送内容」复制原始消息和模型名称，「复制回答」仍只复制回答正文。内容随会话历史保存在本机，之后修改背景、JD 或移除资料不会改写它；请求失败或中途停止也保留已发起请求的文字。旧版回答和提交前停止的请求没有可还原的发送记录。此栏只记录模型输入文字，不包含接口认证头或配置中的 API Key。

会话仍最多保留 50 场，单场 4 MB；完整输入快照会增加会话大小。达到上限时会明确提示新建会话，不会截断输入文字或覆盖之前保存的记录。Markdown 导出保持回答、目标及检索资料的格式，完整模型输入在应用的会话记录中查看或单独复制。

「会话记录」列表及详情页都支持删除，确认后移除该场转写、回答和模型输入快照。删除当前空闲会话会同时清空工作台并开始新的会话；当前会话正在转写或生成回答时，需要先停止。删除记录不影响简历、目标岗位、面试环境、参考资料、模型设置或已导出的文件；失败时保留记录，可重试。

## 百炼远程知识库

在「模型与设置 → 百炼远程知识库」开启「启用远程知识库」。使用自己的 Key 时，填写完整请求地址、已发布的知识检索服务 Agent ID 和独立 API Key，再点击「保存并测试远程知识库」；使用平台时无需填写这些供应商配置，但需要登录且后端已启用知识检索。自带模式的请求地址示例为 `https://{workspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/indices/knowledge/search`，须将 `{workspaceId}` 替换为自己的业务空间 ID；Agent ID 为 `aid-…`。此处接入知识检索接口，知识库和检索策略在百炼控制台管理。

远程开关默认关闭，对所有面试环境生效。开启后只检索百炼，暂停本地知识库检索，无需配置本地向量模型；本地开关和各环境的资料选择保持原样。关闭远程后，才按原本地开关和环境选择恢复本地检索。本地环境勾选不限制云端检索范围，云端范围由自带配置的 Agent 或平台后端的 Agent 决定。简历和岗位 JD 仍直接作为回答上下文，不受此检索切换影响。

远程自带 Key 单独加密保存，不自动复用其他服务 Key；留空保存会保留旧 Key，改用平台前可显式清除。每次回答前仅将当前问题发送到检索接口，请求体为 `agent_id`、`query` 和空 `images`；平台请求使用 `agent_id=platform`，真实 Agent 由后端决定。测试连接使用固定测试问题，不使用简历或会话内容。客户端检索最多等待 5 秒；超时、失败或没有结果时会显示状态，继续根据简历、岗位 JD 和问题上下文生成，不会自动检索或回退到本地资料。停止或更换问题会取消旧请求。平台回答仍独立检查登录与额度，知识降级不能绕过回答授权。

远程接口响应只提取 `data.nodes[].text` 正文，不保留接口的 metadata、文件名、页码、评分或媒体链接，也不会访问这些链接。最多保留 6 个文本片段，每片段最多 2000 字符，总计 6000 字符；发送给回答模型的远程参考内容是纯文本片段列表，不含来源标签、内部 ID 或其他资料属性。回答的「本次检索资料」仍标明百炼来源和当时的 Agent 标识，平台模式记录 `platform`，不会返回服务端真实 Agent；「本次发送内容」展示实际发出的文字。历史和导出保留当时的资料，不随云端内容或设置的后续变更而改变；旧版含来源属性或同时包含本地与远程来源的历史仍可查看，不改写过去实际发送的内容。

## 数据与连接

- 用户自带 Key 与平台业务 Token 在 Electron 主进程中通过系统 `safeStorage` 加密保存，读取设置不会向页面返回凭据；平台供应商 Key 仅服务端配置。
- 原始音频不落盘，开始转写后实时发送到自带配置的阿里云兼容 WebSocket 服务，或经平台 Java 后端中转到其配置的语音服务。
- 生成回答时将问题、最近字幕、已保存个人背景、目标公司/岗位/JD 及实际检索到的片段发送到所选回答模型；平台模式经后端调用。口语提示词和输入快照当前仍由客户端构建。
- 参考资料在本机提取文字和存储；建索引会将片段发送到配置的向量接口。本地检索生效时会发送问题和少量近期上下文，开启百炼远程知识库后暂停这一步。资料库及索引在 `references.sqlite`，原件副本位于 `documents/`，不会写入设置文件。
- 远程知识库仅发送当前问题到自带配置或平台检索接口；云端返回的相关文字会进入回答模型与本机会话历史。自带 URL、Agent ID 和 Key 独立配置，平台使用服务端固定配置；同一次请求使用同一版本的连接配置与凭据。
- Java 后端保存账号、凭证摘要和按用户隔离的资源请求记录。简历、岗位、环境、资料库及会话历史仍使用本机存储，尚无云同步或云端资料库迁移。
- 配置与会话保存于 `~/Library/Application Support/Interview Copilot/`，导出文件由用户选择位置。
- 多份简历、岗位与环境保存在独立 `interviews.json`（总计最多 32 MB），使用稳定 ID 关联，不复制多份原始文件到各环境；原有 settings.json 的单份背景只用于首次迁移。
- 远程接口要求 HTTPS/WSS，本机回环接口允许 HTTP/WS。
- 修改转写配置后需停止并重新开始；回答配置在下次生成时生效。

## 开发与打包

开发测试使用 Node.js 24、macOS 14.2+，目标平台为 Apple Silicon。打包应用自带 Electron 的 Node.js，不需要另行安装 Node 或数据库。

```sh
npm install
npm run dev
npm test
npm run build
npm run test:e2e
npm run test:rag
npm run test:environments
npm run test:remote-knowledge
npm run test:history
npm run test:platform
npm run pack
```

`npm run pack` 生成本地 `.app`，`npm run dist` 可生成 DMG。当前应用采用本地 ad-hoc 签名，未做 Apple 公证；开发时修改的音频权限声明在打包后的 `.app` 中验证最可靠。

ad-hoc 签名的应用更新后，macOS 旧录制授权可能失效，即使系统设置开关仍然开启。此时请完全退出应用，在「系统设置 → 隐私与安全性 → 录屏与系统录音」移除旧的 Interview Copilot，在录屏/仅系统录音列表用「＋」重新添加 `../dist/mac-arm64/Interview Copilot.app`，开启后重新启动。不能仅凭开关为开或父进程启动的自动化测试判断当前应用已授权；持续开发时建议使用稳定的 Apple Development 签名身份。

## 已实现范围

- 系统声音或麦克风择一采集，AudioWorklet 连续重采样为 16 kHz 单声道 PCM16。
- 阿里云 Fun-ASR 双向流，临时/最终字幕修订、停止时尾部提交、错误和超时反馈。
- 转写原位编辑、焦点与光标保护、手动版本保留，逐句生成使用修正后的问题。
- 系统音频持续自动回答：停顿聚合、问句检测、去重、排队、点击待回答句转手动，设置跨重启保存；后台与紧凑模式仍可工作。
- 自定义 Chat Completions 接口；UTF-8 SSE、非流式 JSON、取消与连接测试。
- 直接以候选人第一人称生成口语回答，开头回应当前问题，不列辅导提纲；个人经历按已提供的背景引用，缺少依据时明确以假设方案作答。输出效果取决于所选模型对提示词的遵循程度。
- 个人背景、手动/快捷键提问、Markdown 回答、置顶、紧凑窗口、会话记录和导出。
- 文字 PDF 简历预览导入、公司/岗位/JD、资料库、独立向量配置与本地混合检索，历史保留岗位和来源快照。
- 多份简历与岗位 JD、可创建/切换的面试环境、按环境选择参考资料、默认环境迁移及会话隔离。
- 百炼远程知识库检索接口、开启后仅使用远程的全局开关、连接配置与检索测试、取消和超时反馈、远程来源与历史快照。
- API Key 加密、IPC 边界校验、上下文隔离、过期事件过滤。
- 独立 Java 平台后端接入、账号登录/退出、能力发现、按能力 BYOK 优先、平台工作取消与自带 Key 显式清除。

尚未包含说话人分离或模型语义判题、本地转写模型、音频断线自动补发、扫描 PDF OCR 或 DOCX 导入。商业化范围尚未包含公开注册、支付套餐、简历/资料/历史云同步、正式云部署与签名更新；Windows 和 Intel Mac 的音频、权限与发行适配尚未实机验证。

## 验证说明

`npm test` 检查音频重采样、存储验证、字幕处理与服务协议。`npm run test:e2e` 在独立临时配置目录启动真实 Electron，用本地模拟 HTTP/WebSocket 服务验证交互，不连接真实供应商，也不使用真实 Key。

0.4.0 当前结果：前端 352/352 测试、后端 49/49 测试（含 PostgreSQL 17.11 集成）、11 项 Electron→Java→本地假供应商的平台链路与核心 Electron E2E 42/42 通过。平台检查覆盖逐步 SSE、取消/去重、ASR PCM 中转、退出断开、BYOK 优先及凭据边界。macOS arm64 验收包的 PDF/SQLite 冷启动与签名检查通过；原路径安装文件/链接及四份用户数据校验通过。独立 CUA 会话原路径 UI 验收通过，读取 V0.4.0、尚未开始、00:00、转写/回答空态和空问题，未执行交互操作；详见 [实现记录](../workspace/interview-copilot/notes/impl-backend-separation.md)。

端到端测试截图与报告位于 `test-results/`；真实阿里云识别准确率、网络延迟与实际会议软件音频兼容性，需要在应用中配置真实 Key 后验证，不能从模拟测试推断。
