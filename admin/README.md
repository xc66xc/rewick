# Interview Copilot 管理端

独立 React Web 管理端，连接同源 `/api/v1` 后端。使用与桌面端一致的已锁版本：React 19.2.8、TypeScript 5.9.3、Vite 7.3.6。依赖与锁文件独立。

## 本地开发

```sh
cd admin
npm ci
COPILOT_ADMIN_PROXY_TARGET=http://127.0.0.1:8080 npm run dev
```

默认访问 `http://127.0.0.1:5174`。`COPILOT_ADMIN_PROXY_TARGET` 只供 Vite 的 Node 配置使用，不注入页面。后端需按根目录部署说明配置 bootstrap 管理员并手动执行 `backend/sql/01`–`05`；已完成 `01`–`04` 的库只升级 `05_email_auth.sql`，详见 [SQL 说明](../backend/sql/README.md)。没有默认管理密码。

```sh
npm test
npm run build
```

`npm run preview` 只预览静态构建（端口 4174），不提供开发 API 代理。生产使用下述 Nginx 同源代理。

## 登录和操作

- 登录后再次请求 `/admin/me`，仅 ADMIN 可进入。Bearer 仅保存在内存，刷新需重新登录；401 会清除本地会话。密码提交后清空，不存到浏览器存储。
- 用户管理支持搜索、分页、创建、启停、可用面试时长与变动记录、密码重置及撤销全部登录。时长为 0 时不能开始面试。管理员可以增加、扣除或设定剩余时长，必须填写原因。禁用、重置密码和撤销登录会结束正在进行的面试。新建账号固定 USER。
- 配置包含供应商连接、开放模型目录、默认模型、ASR 和百炼知识库。模型的平台 ID 自动生成且保持稳定，显示名称供客户端选择。供应商 URL / 类型改变时必须重新录入密钥。
- 桌面先邮箱注册/登录，再通过四类服务下拉框显式选择「平台提供」或「我的自定义」。后台模型目录提供回答选项；ASR 与知识库只公开当前启用、带 Key 且绑定模型/Agent 的服务，不把任意未绑定供应商放入列表。当前后台不管理平台向量服务，桌面可自行添加 Embeddings 接口。
- 连接测试提交当前草稿，不发布配置；测试和保存失败保留草稿。Key 只保存在当前编辑页面内存，发布成功、离开配置页或退出登录后清除。GET 从不回显密钥。普通草稿在本次登录的页面导航间保留。
- 配置整体发布并校验版本。409 保留本地草稿，可在核对后选择“重新加载配置”；确认后才丢弃草稿。删除有引用的服务或默认模型前，须先清理引用。发布影响后续新请求，现有 SSE / ASR 使用开始时的配置。
- 调用记录支持用户 ID、能力、状态、模型筛选和分页；操作日志记录操作者、动作、目标及时间。不展示请求或回答正文，不提供费用账单。

平台供应商地址、Key、模型/Agent 绑定与 SMTP 设置只保存在后端数据库，不从 YAML 或供应商环境变量回退。未发布、禁用或下架的服务不会改用其他连接。平台 Key 与邮件密码使用部署侧 `COPILOT_PLATFORM_MASTER_KEY` 加密，页面只取得是否已配置；用户自定义 Key 留在桌面设备。

## 邮件服务

「邮件服务」用于配置邮箱注册验证码的 SMTP 连接：主机、端口、用户名、密码、发件邮箱及 STARTTLS / SSL。启用并保存后供新注册使用；部署还需独立的 `COPILOT_EMAIL_CODE_SECRET`。`COPILOT_EMAIL_REGISTRATION_ENABLED=false` 可应急关闭发送与注册，已有账号仍可登录。

- 「测试连接」提交当前草稿，只验证 SMTP 连接和认证，不发送邮件，也不保存配置；失败保留草稿以便修改。
- 「保存邮件配置」按版本保存；遇到 409 保留草稿，在确认「重新加载邮件配置」后才丢弃。页面不会覆盖其他管理员的新版本。
- 密码只写不回显。同一连接留空保留已保存密码；修改主机、端口或用户名且继续认证时必须重新填写。用户名留空表示无需认证，保存时清除旧密码。
- STARTTLS 与 SSL 互斥；远程 SMTP 必须启用其中一种，仅本机回环允许明文测试。密码只保留在当前草稿内存，保存成功、离开页面或退出后清除。

管理员账号仍使用原用户名与密码登录管理台；邮箱验证码用于桌面用户注册，不自动把普通用户提升为管理员。

## Docker

根目录 Compose 可使用 `build.context: ./admin`，容器端口 80。`nginx.conf` 将 `/api/` 代理到 `http://backend:8080`，关闭缓冲以支持 SSE。页面不需要供应商密钥环境变量。公网部署由外层网关终止 HTTPS；默认开发和 Compose 端口绑定本机。

## 真实浏览器验证

本次已通过 20 项组件测试与生产构建，新增邮件页的桌面/390px 浏览器检查无页面错误或横向溢出。真实 Java、隔离 PostgreSQL 与本机 SMTP 上的 7 组管理端浏览器操作通过，包含邮件草稿连接测试与保存；这些操作计入完整平台链路的 26 项检查。本次不涉及正式数据库升级或桌面安装包更新。

此前 2026-09-08 的管理端 Nginx 镜像构建及实际容器登录页检查属于历史验收。

```sh
COPILOT_ADMIN_URL=http://127.0.0.1:5174 \
COPILOT_ADMIN_USERNAME=隔离管理员 \
COPILOT_ADMIN_PASSWORD=隔离管理员密码 \
COPILOT_ADMIN_SMOKE_OUTPUT=test-results/smoke \
npm run test:smoke
```

脚本只用于隔离测试后端，会创建 `admin-smoke-*` 用户、编辑平台配置、测试并保存邮件草稿，执行已启用能力的真实测试接口，需使用本机假供应商和 SMTP。成功或失败清理阶段会尽力恢复配置并停用自己创建的测试用户；不会改动其他用户。截图与报告仅包含隔离测试数据。

也可导入 `scripts/smoke.mjs` 的 `runAdminSmoke({baseUrl,username,password,output})`。脚本不会启动或关闭后端、修改环境变量配置、读取生产凭据；由上层集成脚本管理隔离后端和 Vite 进程。浏览器需安装对应 Playwright Chromium。

根目录执行 `npm --prefix frontend run test:platform` 可自动启动隔离数据库、Java 后端和管理端，联测桌面自选模型与管理页面。需先安装两个前端包、构建桌面及后端，并准备数据库镜像，参见根 README。

生产静态页面另通过实际 Nginx 镜像验证登录渲染、CSP、缓存及安全响应头：

```sh
# 在项目根目录执行，不使用真实账号或供应商
docker build -t interview-copilot-admin:local admin
npm --prefix admin run test:static
```

该检查使用并清理自己的临时容器，不执行登录或调用供应商。

## 逐条保存与刷新登录

服务和模型各有独立保存按钮，默认模型、转写和知识库设置也分别保存。保存只提交该记录与已保存配置，其他未完成草稿保留；模型需先保存关联服务，首个开放模型成为默认项。删除已保存记录确认后立即生效。后台仍以版本校验避免覆盖他人更改。刷新恢复当前标签页会话并先校验权限；不保存登录密码或供应商密钥，退出/过期/401清除凭证。

## 统一模型配置

平台配置每个模型仅一张表单，合并连接地址、Key、显示名称、模型名称及启用状态；保存原子更新连接和模型目录，默认模型自动维护。现有服务和模型自动合并展示，无需重填Key。已保存条目可直接启用/停用，停用后桌面刷新目录即不可见；桌面每60秒同步，也可手动刷新。当前转写与知识库分别只有一个激活绑定，新服务启用将切换该能力。
